# NI FITNESS Mini App v4

В версии 4:
- рабочий профиль;
- фактически съеденная доля порции (0–300%);
- точный список покупок на 7 дней в граммах/кг;
- реальные замены ингредиентов внутри конкретного приёма пищи;
- загрузка фото из галереи и отдельная кнопка камеры;
- 100 упражнений из Exercise Encyclopedia с изображениями;
- раздел «Гайды и материалы» с полными PDF и короткими материалами по питанию.

Публикация: загрузить содержимое папки проекта в существующий Vercel project и выполнить Deploy.
