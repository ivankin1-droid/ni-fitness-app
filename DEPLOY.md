# Публикация NI FITNESS Mini App v3

## Вариант 1 — Vercel
1. Подключите Vercel в ChatGPT.
2. Создайте новый проект из этой папки/репозитория.
3. Framework Preset: Other.
4. Build Command: оставить пустым.
5. Output Directory: оставить пустым.
6. После публикации получите HTTPS URL вида https://...vercel.app

## Подключение к Telegram
Откройте @BotFather → /mybots → nifitnesspro_bot → Bot Settings → Menu Button / Configure Mini App.
Укажите HTTPS URL опубликованного приложения.

Если Mini App уже подключён к старому URL, замените URL на новый.

## Как редактировать дальше
- data.js — рацион и упражнения
- index.html — тексты и блоки
- styles.css — дизайн
- app.js — логика
После сохранения и повторного деплоя новая версия появится по тому же адресу.
